# Research Summary

**Domain:** Unification of Terminology ("Guardia" → "Turno") across Sistema de Turnos  
**Date:** 2026-10-06  
**Status:** Complete  

## Executive Summary

The project goal is to systematically replace all occurrences of "guardia" with "turno" (and plural/contextual variants) across user-visible surfaces of the **Sistema de Turnos** desktop application. Research confirms that this change should encompass:
1. The CustomTkinter graphical user interface (buttons, badges, status texts, dialogs)
2. Monthly Excel reports and legends generated by `ExcelHandler`
3. Email notification templates and subjects in `EmailNotifier`
4. Project documentation (`README.md`, `CLAUDE.md`, `POLITICAS_Y_SEGURIDAD.md`)
5. Corresponding regression test assertions in `tests/`

Internal algorithm variable names and `config.json` database keys are explicitly excluded to guarantee backwards compatibility and prevent state drift.

## Key Recommendations

- **Grammar-First Approach:** Ensure masculine gender agreement in Spanish throughout (e.g., "el turno", "los turnos", "al turno").
- **Layered Execution:**
  - Phase 1: Presentation Layer & Dialogs (`views/`)
  - Phase 2: Excel Reports & Email Notifications (`utils/`)
  - Phase 3: Documentation & Automated Test Verification (`docs/`, `tests/`)
- **Regression Prevention:** Run pytest after each layer's modification to ensure zero regressions in business logic.
